# FastPix Data SDK — Examples

Two standalone apps showing the **FastPix Video Data Core SDK** attached to
Apple's **AVPlayer**, one per UI paradigm:

- [`UIKit/`](UIKit) — `AVPlayerViewController` (iOS 15+)
- [`SwiftUI/`](SwiftUI) — `VideoPlayer` (iOS 16+)

Each folder is self-contained — open its `.xcodeproj`, press **▶ Run**, then
watch views on [dashboard.fastpix.com](https://dashboard.fastpix.com). See each
project's README for details.
